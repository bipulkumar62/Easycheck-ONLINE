## Rules

- Keep the app icon square and pre-padded so Play’s rounded mask does not clip the mark.
- Keep the feature graphic free of unverifiable claims and internal technology names.
- Use real app screenshots, not mockups with invented data.
- Re-run the screenshot generator after UI changes so the listing stays accurate.
- Store listing copy and the submission checklist live in
  `project_docs/phase_23_authentication_approval/PLAY_STORE_READINESS.md`.
